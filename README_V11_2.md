# KIKI V11.2 — 2D Frontend Build

This build intentionally uses the KIKI 2D illustrated/CSS frontend and does not include the WebGL/3D world renderer.

## Included
- Cozy 2D KIKI home screen
- Create Room / Join Room frontend
- Mobile-safe form scrolling
- Portrait-friendly 2D room view
- Existing multiplayer room/game logic preserved
- Existing pet sounds preserved
- Existing games, chat, voice and scoreboard preserved

## Removed
- WebGL/3D world renderer
- 3D canvas from the room view
- Landscape-only rotation gate
